# Voci-Trainer

Vokabel-Übungs-App für Schülerinnen und Schüler (English File Pre-Intermediate, A2).

Ein Projekt von **SeetalIT** · [seetalit.ch](https://seetalit.ch) · Paul Emmenegger, Hochdorf

- `index.html` – die App (eine Datei, kein Build nötig)
- `books/` – Wortlisten, eine JSON-Datei pro Buch (`books/index.json` listet sie)
- Schalter (App an/aus, freigeschaltete Kapitel) und Lehrer-Login laufen über Supabase.

Neues Buch: JSON nach `books/` legen und in `books/index.json` eintragen.
